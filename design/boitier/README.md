# Boîtier — recherche de forme

`cinq-formes.html` est une planche de recherche esthétique pour l'objet de bureau
iBurned : cinq façons de transformer la mascotte Claude Code en petit boîtier qui
affiche la jauge de consommation.

Page statique autonome — aucune dépendance au build Next.js. À ouvrir directement
dans un navigateur.

Tout est construit sur la trame du sprite : angles à 90°, aucun congé, quatre
pattes, deux ergots latéraux, chevrons `>` `<` en guise d'yeux.

Contenu : les cinq directions dessinées (élévation avant, état affiché, fiche
couleur / matière / finition), une carte à deux axes qui situe les directions les
unes par rapport aux autres, un alignement à la même échelle avec une tasse comme
repère, et une recommandation de ce qu'il faudrait maquetter en premier.

Les volumes sont indicatifs : rien n'est coté, et rien ici ne préjuge de
l'électronique embarquée.
